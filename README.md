# Programa-em-C-que-identifica-quantas-vogais-foram-digitadas
Este é um programa em C, feito no Falcon C++, em que o usuário digita quantos caracteres quiser, e no final é impresso quantas vogais foram digitadas.

Foi feito em meados de abril de 2026, estudando para as provas do professor Ricardo Casseb, de Programação 1, no Cesupa.

No início, introduzo com int o contador das vogais, o contador do loop (i), “símbolo” como uma variável de caracteres, que servirá para ser atribuída ao símbolo que o usuário digitar, e o x, que servirá para escanear a quantidade de símbolos que o usuário vai digitar.
O programa solicita ao usuário a quantidade de símbolos que deseja digitar e utiliza um laço while para receber cada símbolo individualmente. A cada entrada, verifica se o caractere é uma vogal, maiúscula ou minúscula. Caso seja, incrementa a variável vogais. Ao final, exibe a quantidade total de vogais digitadas.
